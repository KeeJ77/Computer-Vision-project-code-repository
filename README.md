# Computer-Vision-project-code-repository

## Download and Usage Instructions

1. Download the file.
2. Upload the file to Google Colab.
3. Make sure to select **T4 GPU** in the Colab menu (Runtime -> Change runtime type -> T4 GPU).
4. Link to your existing Weights & Biases account.
   - You can link a Google account in that one step.
   - **Note**: If the linking fails, you can still run the remaining cells; it won't affect the rest of the operations.
